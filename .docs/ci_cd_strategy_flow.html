Estratégia 1: Build no GitHub Actions & Pull Leve no Coolify

Zero Sobrecarga na VPS

A compilação de código, download de dependências (pip) e geração da imagem ocorrem 100% no cluster de runners da GitHub Cloud com 16GB de RAM.

Deploy em Segundos

O Coolify apenas recebe o webhook e executa o docker pull da imagem final. O deploy passa de 5 minutos travando para menos de 10 segundos lisos.

Imutabilidade & Rollback

Cada release no GHCR gera uma tag por commit SHA. Se um deploy falhar, é possível voltar à imagem estável anterior instantaneamente sem novo build.
